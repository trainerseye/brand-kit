# TrainersEye Brand Kit

Logos, colours and usage rules for press, partners and app-store listings.

## Name
- Write **TrainersEye** (one word, capital T and E). Not "Trainers Eye" or "Trainer's Eye".
- Company: **TrainersEye Technologies LLC**
- Products: **TrainersEye: Physio & AI Coach** · **MoPro AI** · **MoPro Codex API**

## Usage
- Leave clear space around the logo at least equal to the height of the "T".
- Don't stretch, recolour, add effects or put the logo on busy photos.
- On dark backgrounds use the cream or white version.
